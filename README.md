# Shkatulka — Pattern Bundles Page

Product page for curated sewing-pattern bundles: gallery, bundle contents, pricing and FAQ, matching the Shkatulka store design.

**Live demo:** [daryaulida.github.io/package-page/](https://daryaulida.github.io/package-page/)

![Preview](preview.png)

## Features

- Product gallery with slider
- Bundle contents and pricing blocks
- FAQ and contacts
- Responsive layout

## Tech stack

HTML · CSS · JavaScript

## Run locally

No build step — clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/daryaulida/package-page.git
```
